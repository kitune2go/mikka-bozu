# 『三日坊主以降の坊主』コンセプト

この文書は、今後の脚本・プロット・作画生成で参照する作品コンセプトの基準です。

## 一文定義

**「三日坊主」の4日目以降という未定義領域を、坊主・寺院・資格・労働・休養・組織などの制度として文字どおり実装し、素朴な疑問が巨大な制度へ発展していく過程を描く制度風刺ギャグ漫画。**

## 中心テーマ

出発点は「続けることは、本当に無条件に偉いのか？」という問い。

作品は継続そのものを否定しない。扱うのは、継続・努力・休息・中断・再開に対して社会が付与する価値や制度である。

基礎となる考え方は次の3点。

- やる自由
- やめる自由
- 再開する自由

これらを真面目に制度化すると、規則・資格・担当者・組合・審査・書類が増殖していく。その過剰な制度化を笑いにする。

## 世界観の基本原理

### 「○日坊主」が実在する

三日坊主、四日坊主、五日坊主……という言葉を比喩ではなく、実際の分類・肩書き・立場として扱う。

継続日数が増えるにつれて、未定義だった世界が勝手に制度化されていく。

### 寺院と現代組織が混在する

寺院は宗教施設としてだけでなく、行政機関・企業・学校・労働組合・資格団体のようにも振る舞う。

そのため、僧侶が次のような言葉を真顔で使ってよい。

- 資格
- 更新講習
- 労働基準
- 組合
- 休暇
- 担当者
- 審査
- 実績
- 規則
- 申請書・提出書類

**古い寺院の見た目と、現代的な制度用語のミスマッチ自体がギャグである。**

## ギャグの基本エンジン

### 1. 慣用句・価値観を文字どおり実装する

例：

- 「三日坊主」→ 本当に三日で分類される坊主
- 「継続しない権利」→ 権利として制度化する
- 「休暇担当」→ 本当に役職を設置する

### 2. 小さな疑問から制度を肥大化させる

基本形：

**素朴な疑問 → 正論 → ルール化 → 役職化 → 組織化 → 想定外の巨大化**

論理そのものは大きく間違っていないが、結論の規模だけがおかしくなる状態を狙う。

### 3. 解決策が次の問題を生む

基本形：

**問題 → 制度を作る → 一応解決 → 制度そのものが新しい問題になる**

一話できれいに世界を解決し切らない。

**改善するたびに世界が少し面倒になる**ことが、シリーズ継続のエンジンになる。

## 主人公の機能

黒髪の青年が、読者側の素朴な常識と感情を担当する。

基本的な動きは次のとおり。

1. おかしな制度・慣習に気付く
2. 素朴な疑問を口にする
3. 正論らしい改善案を出す
4. 勢いよく改革を進める
5. 改革が予想以上に巨大化する
6. 本人も結果に驚く

主人公は皮肉屋ではなく、基本的には善意で動く。そこから制度が暴走する方が、この作品らしい。

## 坊主たちの機能

坊主は主人公に対する低温側の存在。

- 主人公：感情、運動、叫び、直感
- 坊主：真顔、理屈、規則、事務処理

主人公が大騒ぎしても、坊主は淡々と議題を処理する。

坊主を全員ギャグ顔にしない。**登場人物自身は、この世界をギャグだと思っていない。**

## トーン

基本は **「真顔の不条理」**。

作者や登場人物が読者へ「ここが面白い」と説明しない。

世界の側が極めて真面目であるほど、読者から見た不条理が強くなる。

避けるもの：

- メタ発言に頼る
- 登場人物全員がツッコミ役になる
- 最初から制度を悪として描く
- 教訓を説明しすぎる
- 一話ごとに完全解決する

## エピソード設計の目安

1話では原則として一つの制度テーマに集中する。

例：

- 資格制度
- 更新講習
- 労働基準
- 組合
- 休暇申請
- 休暇担当

タイトルは既存シリーズに合わせ、原則として以下の形式を使う。

**「○日坊主、○○する」**

## 作品として守ること

- 「三日坊主」の語義拡張から世界を作る
- 正論と制度肥大化をセットにする
- 主人公と坊主の温度差を保つ
- 古い寺院と現代制度を自然に混在させる
- 問題解決の副作用を次の物語資源にする
- 継続を単純に善、挫折を単純に悪として扱わない
