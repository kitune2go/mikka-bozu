# 『三日坊主以降の坊主』絵柄・作画ガイド

この文書は、今後の漫画ページ作画・画像生成・修正時に参照する視覚仕様の基準です。

## 基本方針

**モノクロ日本漫画。少年漫画的なキャラクター表現と、青年漫画寄りの背景密度を組み合わせる。**

人体・寺院・家具などはある程度具体的に描きつつ、感情表現だけは漫画的に大きく誇張する。

絵柄の核は次の対比。

- 主人公：大きく動く、叫ぶ、汗をかく
- 坊主：ほぼ動じない、真顔、淡々としている

**「叫ぶ主人公 + 無表情の坊主」**を代表的な画面構造として扱う。

## 色・線・質感

- 基本は完全なモノクロ漫画
- 黒ベタを明確に使う
- グレーはスクリーントーン相当の処理
- 輪郭線は細すぎず、漫画として明瞭にする
- 写真調・3DCG調には寄せない
- 水彩・カラーイラスト調にはしない
- 背景を真っ白にしすぎず、寺院の空間情報を残す

## 主人公

### 固定したい特徴

- 若い男性
- 黒い短髪
- ややツンツンした髪型
- 大きめの目
- 太めで感情が出る眉
- シンプルな現代服
- 長袖トップスを基本とする
- 坊主ではないことが一目で分かる髪型と服装

### 表情・動き

主人公は画面の「熱」を担当する。

よく使う表現：

- 大きく口を開けて叫ぶ
- 汗
- 驚き顔
- 指差し
- 拳を握る
- 両手を広げる
- 前のめりになる
- 勢い線

静かな会話でも、必要な場面では坊主より明確に表情を出す。

## 坊主

### 固定したい特徴

- 剃髪
- 僧衣・和装
- 年齢差を持たせてよい
- 基本的には落ち着いた顔
- 半目、真顔、軽い困惑程度を多用
- 数珠、書類、小冊子などを持たせてよい

### 群衆としての坊主

坊主は個人キャラクターであると同時に、制度や組織を視覚化する群衆として使う。

そのため、次の構図を積極的に使ってよい。

- 複数の坊主が整列している
- 会議している
- 同じ方向を向いている
- 書類を持っている
- 組合・講習・審査などの集団場面

全員に派手なリアクションをさせない。

## 背景・舞台

基本舞台は日本の寺院。

主な要素：

- 畳
- 木造建築
- 柱
- 障子
- 廊下
- 寺門
- 座敷
- 木製机
- 黒板

一方で、現代組織の道具を平然と混在させる。

例：

- ファイル
- ノート
- 書類
- 名札
- 掲示物
- 教材
- マグカップ
- 会議資料
- 組合掲示

この不自然さはエラーではない。**「寺院 + 現代事務」の混在は作品固有の美術設計である。**

## ページ構成

現行シリーズでは、1ページを大きく4区画に分ける構成を基準とする。

```text
┌────────┬────────┐
│   ②    │   ①    │
├────────┼────────┤
│   ④    │   ③    │
└────────┴────────┘
```

日本漫画の読み順に合わせ、基本は

**右上 → 左上 → 右下 → 左下**

とする。

必ずしも完全な均等4分割である必要はないが、1ページ内の情報量とテンポは既存ページを基準にする。

## タイトル

ページ上部に話数・タイトルを置く場合、既存シリーズとの統一を優先する。

基本形式：

**第○話「○日坊主、○○する」**

タイトル文字は本文より明確に大きくする。

## セリフ・文字表現

- 通常会話は漫画の吹き出しで処理
- 日本漫画として自然な縦書きを基本とする
- 長文を詰め込みすぎない
- 制度用語・結論・オチは大きな文字で強調してよい
- トゲ吹き出し、極太文字、黒板、張り紙、横断幕などを使い分ける

重要語を視覚的に「制度の名称」として見せることが、この漫画の特徴になる。

例：

- 「継続しない権利」
- 「三日坊主制度 廃止」
- 「全日本○○組合」
- 人数・日数などの異常に大きい数字

## カメラ・演出

同じ正面構図だけを続けない。

使える画角：

- バストアップ
- 顔のアップ
- 引きの会議室
- 寺院外観
- 群衆の俯瞰
- 主人公を前景、坊主を背景に置く構図
- 坊主の静かな反応を大きく抜く構図

オチのコマでは、文字・人数・組織の規模を大きく見せるため、引きの構図を使うことがある。

## 表情設計の原則

この作品では「全員が面白い顔をする」必要はない。

むしろ、次の温度差を維持する。

| 役割 | 表情・動き |
| --- | --- |
| 主人公 | 高温。驚く、叫ぶ、動く |
| 坊主 | 低温。真顔、半目、淡々 |
| 群衆 | 秩序だった静けさ |
| オチ | 状況・文字・規模で笑わせる |

## 作画時に固定する要素

以下は原則として毎回維持する。

- モノクロ日本漫画
- 黒髪青年の主人公
- 主人公の大きなリアクション
- 坊主の低リアクション
- 日本寺院
- 現代制度・事務用品との混在
- 背景に一定の描き込み
- 黒ベタとグレートーン
- 吹き出し中心の会話
- 制度語・オチの文字強調
- 必要に応じた群衆坊主

## 話ごとに変えてよい要素

- カメラアングル
- コマの厳密な大きさ
- 坊主の人数
- 寺院内の部屋・背景位置
- 小道具
- 主人公のジェスチャー
- 強調文字の配置

## 避けたい絵柄ブレ

- フルカラー化
- 萌え絵・美少女漫画への寄せすぎ
- 劇画として写実に寄せすぎる
- 3Dレンダーのような質感
- 坊主全員をコミカルな変顔にする
- 主人公の髪型・年齢感を毎回変える
- 寺院要素を消して普通のオフィス漫画にする
- 背景を省略しすぎて世界観が見えなくなる
- 左から右へ読む海外コミック式レイアウト

## 画像生成用の短縮アンカー

新規作画時に最低限伝える共通仕様：

> モノクロの日本漫画。黒髪短髪の若い男性主人公と、剃髪で僧衣姿の無表情な坊主たち。日本の伝統的な寺院を舞台に、書類・黒板・会議・組合など現代的な制度要素が混在する。主人公は大げさな表情とジェスチャー、坊主は淡々とした低リアクション。少年漫画的な人物表現と、やや密度の高い寺院背景。黒ベタとグレースクリーントーン。日本漫画の右から左の読み順。

これはベース指定であり、各話の具体的な脚本・構図・セリフを上書きしない。
